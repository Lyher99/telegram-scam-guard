# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability or an evasion technique in Telegram Scam Guard, please report it responsibly:

- Please do not open public issues for security vulnerabilities.
- You can report issues by reaching out via GitHub Security Advisories or contacting the maintainers directly.

## Safety Guidelines

- **Never execute untrusted files:** This project is designed to inspect metadata and magic signatures only.
- **Data Privacy:** Raw chat logs containing Personally Identifiable Information (PII) must not be committed to the repository.
